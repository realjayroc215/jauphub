# JAUP Unified Platform

A full Next.js + Cloudflare Pages deployment containing:

- JAUP Command Center
- JAUP Drive
- JAUP Office Agent
- JAUP Swarm Mission Control
- JAUP Security / Philly Guard
- JAUP Core Engine
- JAUP API Layer
- JAUP UI Library

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Deploy to Cloudflare Pages using the generated output in the .vercel/output folder.
